# 企业智能融资匹配平台

本地可运行的全栈 Agent 系统：前端（静态单页）+ 后端（FastAPI）+ 存储（SQLite）+ 模型调用（DeepSeek，可选）。流程：上传产品说明书 PDF 入库 → 对话录入融资需求 → 缺项追问 → 分次调取政务数据（需授权）→ 准入预审 → 排序推荐 → 客户经理确认 → 政府视图与报告。预审结果仅供参考，不是授信审批，确认只保存对接单，不提交贷款申请。

## 1. 环境依赖

| 项 | 要求 |
| --- | --- |
| 操作系统 | macOS / Linux（`start.sh` 是 bash 脚本）。Windows 请用第 2.1 节手动命令，未实测 |
| Python | 3.9 及以上（实测版本 3.9.6） |
| 网络 | 依赖已随工程放在 `vendor/wheels/`（macOS arm64/x86_64、Linux x86_64/aarch64、Windows x64；Python 3.9–3.12），安装不需要联网。只有调用模型才需要访问 `api.deepseek.com`（可选） |
| 依赖包 | [requirements.txt](requirements.txt)：fastapi、uvicorn、python-multipart、pdfplumber、openpyxl、httpx、pytest，由安装步骤自动装入虚拟环境 |
| 数据 | 仓库自带：`数据/融资数据.sqlite`（种子库，只读）、`数据/产品/*.pdf`（11 份说明书） |
| 模型密钥 | 可选。不配置也能完整运行（全部走本地规则），配置后启用 DeepSeek 辅助（见第 5 节） |

## 2. 安装与启动（一键）

```bash
cd src/v1
./start.sh
```

**Windows**：双击或运行 `start.bat`（逻辑相同，未实测）。**交付打包**：`./package.sh` 生成 `../融资匹配平台-交付包.zip`，已排除 `.venv`、`.env`（含密钥）、`runtime/`。首次启动在终端里会询问是否输入 DeepSeek API Key，回车跳过则使用本地规则；启动完成后会打印 `/api/health`，其中 `model` 字段显示当前是否在调用 deepseek-v4.1-flash。

脚本依次完成：检查 Python 3.9+ 与端口占用 → 创建 `.venv` → 从 `vendor/wheels/` 离线安装依赖（不需要联网；本机平台没有匹配包时才回退 PyPI） → 没有 `.env` 时从 `.env.example` 生成 → 启动服务 → 产品表为空时自动入库 11 份示例说明书 → 打开浏览器。看到 `Uvicorn running on http://127.0.0.1:8000` 即启动成功，`Ctrl+C` 停止。

环境变量：

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `PORT` | 服务端口 | `8000` |
| `NO_BROWSER=1` | 不自动打开浏览器（远程、无界面环境用） | 自动打开 |
| `PYTHON` | 创建虚拟环境用的解释器，例如 `PYTHON=python3.11` | `python3` |

示例：`PORT=8080 NO_BROWSER=1 ./start.sh`

### 2.1 手动安装与启动

```bash
cd src/v1
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env            # 可选：填写 DEEPSEEK_API_KEY
.venv/bin/python -m uvicorn finmatch.server:app --host 127.0.0.1 --port 8000
```

手动启动不会自动入库产品：打开页面进入「产品管理」，点「上传数据包内 11 份说明书」；没有入库的产品不参与预审。Windows 把 `.venv/bin/` 换成 `.venv\Scripts\`。

## 3. 端口与访问地址

| 内容 | 地址 |
| --- | --- |
| 页面 | <http://127.0.0.1:8000/> |
| 健康检查 | <http://127.0.0.1:8000/api/health>，返回 `{"ok":true,"products":11,...}` |
| 接口文档（FastAPI 自动生成） | <http://127.0.0.1:8000/docs> |

- 默认只监听 `127.0.0.1`，仅本机可访问。需要局域网访问时把 `--host` 改成 `0.0.0.0`；系统没有登录鉴权，角色由页面右上角声明，不要暴露到公网。
- 页面右上角切换角色：**客户经理**（产品管理、对话工作台、企业画像、政府视图、报告、方案列表）、**政府人员**（企业画像、政府视图、报告、方案列表，只读）。
- 对话工作台左侧是会话记录，名称为「公司名称 · 新建会话日期」，可新建、切换。

## 4. 快速验证

1. 打开页面，保持「客户经理」角色，进入「对话工作台」，点「＋ 新建会话」。
2. 输入：`华峻精密制造有限公司要流动资金 100 万，12 个月`，应返回预审结果（推荐名单最多 3 个，每个带额度、利率区间和「产品库区间，不是授信审批结果」），并出现「确认方案 / 放弃」卡片。
3. 继续输入 `期限改成 360 天`，应追问「请告诉我几个月」，不会折算成 12 个月。
4. 点「确认方案」（不需要先选产品），进入「方案列表」，应能看到该方案的「人工确认的产品」（确认时的推荐名单）和「确认时间」。
5. 命令行检查：`curl http://127.0.0.1:8000/api/health`。

## 5. 配置对话模型（可选）

- 编辑 `.env`，填写 `DEEPSEEK_API_KEY=你的密钥`，重启服务。模型固定为 deepseek-v4.1-flash（接口名 `deepseek-flash`），不可通过配置更换。
- 不填密钥，或密钥无效、网络不通、余额不足时，系统自动回退到本地规则，对话与预审照常工作，调用过程里会记录模型调用失败原因。
- 预审、排序、统计、授权判断始终由代码完成，模型只做意图提议、补缺和解读，输出都经过代码校验。外送内容仅限用户原话与结果摘要，不含信用代码、法定代表人和明细。
- `.env` 已在 `.gitignore` 中，不要提交；密钥一旦泄露请到服务商处作废重建。

## 6. 数据与重置

- 首次启动把种子库复制成工作库 `runtime/工作数据.sqlite`，产品、会话、方案、调用链都写在工作库，种子库不改动。
- 重置全部数据：停止服务，删除 `runtime/` 目录，重新启动（`start.sh` 会重新入库示例产品）。

## 8. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `./start.sh: Permission denied` | 执行 `chmod +x start.sh`，或用 `bash start.sh` |
| 启动报 `[Errno 48] ... address already in use`（Linux 为 `[Errno 98]`） | 端口被占用。换端口：`PORT=8001 ./start.sh`；或查占用进程 `lsof -nP -iTCP:8000 -sTCP:LISTEN` 后 `kill <PID>` |
| `bad interpreter: .../.venv/bin/python: No such file or directory` | 压缩包里带了别人机器上建的 `.venv`，虚拟环境不能跨机器、跨目录使用。`start.sh` 现在会自动检测并删除重建；手动运行时执行 `rm -rf .venv` 再按第 2 节重建。打包交付时请排除 `.venv/`、`.env`、`runtime/` |
| 安装依赖失败、卡住 | 平台或 Python 版本不在离线包范围内（如 Python 3.13、32 位系统）时才会联网回退，此时需要能访问 PyPI。可设置镜像：`PIP_INDEX_URL=<镜像地址> ./start.sh`；已经装了一半时删除 `.venv` 重来 |
| `python3: command not found` 或版本低于 3.9 | 安装 Python 3.9+，再用 `PYTHON=python3.11 ./start.sh`；已存在旧的 `.venv` 时先删除它 |
| pip 提示 `You are using pip version ...` | 只是升级提示，可忽略 |
| 页面能打开但「产品管理」为空、预审没有产品 | 手动启动时需点「上传数据包内 11 份说明书」；也可 `curl -X POST http://127.0.0.1:8000/api/products/upload-samples` |
| 页面样式或按钮不是最新 | 强制刷新（macOS `Cmd+Shift+R`，其他系统 `Ctrl+F5`） |
| 页面提示「当前角色无权访问该功能」 | 角色不对：产品管理、对话、确认方案需「客户经理」，政府人员只读 |
| 回复里没有「AI 解读」，或调用过程里模型调用失败（如 HTTP 401） | 没配密钥、密钥无效或余额不足。系统已回退本地规则，功能不受影响；检查 `.env` 后重启 |
| 说「已授权」后仍提示待授权 | 授权要对应当前会话里待授权的企业；也可直接点页面上的「同意授权并继续预审」 |
| 想清空所有会话和方案 | 见第 6 节，删除 `runtime/` 后重启 |
