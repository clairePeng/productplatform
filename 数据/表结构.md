# 表结构

`融资数据.sqlite` 的表名和列名都是英文。库内 `table_schema` 与本文件的列目录一致。

本库只有企业、税务、社保、司法和历史融资。产品不在库里。11 份产品说明书是同目录 `产品/` 下的 PDF。

企业侧以 `enterprise` 为枢纽。预审时用企业字段对照说明书第三条至第六条，不在库内做产品连接。

## 读库口径

- 基准日是 2026-09-23。成立年限按周年计算，未到周年日不算满。
- 金额单位是人民币万元。
- INTEGER 列中 1 表示是，0 表示否，空表示未获取。
- 是否参与预审为「否」的列不能用来否决或放行。
- 额度、利率、期限、用途、区域、行业和准入下限读产品说明书第三条至第六条。导语、附章与这两条不一致时，以这两条为准。

## 关联

外键都指向主键。一对一的从表主键就是关联列。多对一的从表另有自己的主键。

| 从表 | 关联列 | 主表 | 主键 | 基数 |
| --- | --- | --- | --- | --- |
| tax | enterprise_id | enterprise | enterprise_id | 一对一 |
| social_security | enterprise_id | enterprise | enterprise_id | 一对一 |
| judicial | enterprise_id | enterprise | enterprise_id | 一对一 |
| dishonest_record | enterprise_id | enterprise | enterprise_id | 多对一 |
| enforcement_record | enterprise_id | enterprise | enterprise_id | 多对一 |
| closed_civil_case | enterprise_id | enterprise | enterprise_id | 多对一 |
| financing_history | enterprise_id | enterprise | enterprise_id | 多对一 |

- `dishonest_record`、`enforcement_record`、`closed_civil_case` 挂在 `enterprise` 上，不挂在 `judicial` 上。失信限制只看 `judicial.is_dishonest` 和 `judicial.is_enforced`。已结民事案件不构成失信限制。
- `enterprise.data_authorization` 不是「已授权」时，不读取 `tax`、`social_security`、`judicial`、`dishonest_record`、`enforcement_record`、`closed_civil_case`、`financing_history`，不做预审。
- `table_schema` 只说明列，不与业务表关联。

预审时，企业字段对照产品说明书第三条至第六条：

- 对话中的企业名对 `enterprise.enterprise_name`，必须完全一致。
- 用途、区域、行业、额度、期限、年化利率、担保方式、纳税等级下限、参保人数下限、成立年限、纳税额下限、科技资质和纳税人资格，读 `产品/*.pdf`。区域或行业写明「不限」时，不因这一项否决。
- `enterprise.region` 对说明书第四条的适用区域，`enterprise.industry` 对适用行业。
- `tax.tax_credit_rating` 对第六条的纳税等级。等级从高到低为 A、B、M、C。
- `social_security.insured_count` 对第六条的参保人数。
- `tax.tax_paid_12m_wan` 对第六条的近 12 个月纳税额。
- `tax.taxpayer_type` 对第六条的纳税人资格。说明书没有这项要求则不比。
- 说明书要求科技资质时，`is_high_tech`、`is_specialized`、`invention_patent_count` 满足其一即可。
- 客户指定了担保方式时，对第五条的担保方式。
- 金额和期限对第五条、第三条。利率优先用第五条利率上限，额度优先用第五条额度上限，最后用说明书首页的产品编号。

## enterprise

企业工商。一家企业一行。

| 列 | 类型 | 含义 | 是否参与预审 |
| --- | --- | --- | --- |
| enterprise_id | TEXT | 主键 | 否 |
| enterprise_name | TEXT | 企业名称。与对话里的企业名完全一致才算收录 | 是 |
| credit_code | TEXT | 统一社会信用代码 | 否 |
| legal_representative | TEXT | 法定代表人 | 否 |
| founded_date | TEXT | 成立日期，YYYY-MM-DD。成立年限只看这一列 | 是 |
| approved_date | TEXT | 核准日期。干扰，不能用来计算成立年限 | 否 |
| business_status | TEXT | 经营状态。在营才通过 | 是 |
| enterprise_type | TEXT | 企业类型。干扰 | 否 |
| registration_authority | TEXT | 登记机关 | 否 |
| registered_capital_wan | INTEGER | 注册资本，万元 | 否 |
| paid_in_capital_wan | INTEGER | 实缴资本，万元。干扰 | 否 |
| region | TEXT | 区域。只看这一列，不看 registered_address | 是 |
| registered_address | TEXT | 注册地址。干扰，地址里的城市不能代替 region | 否 |
| industry | TEXT | 行业。只看这一列 | 是 |
| industry_section | TEXT | 行业门类。干扰 | 否 |
| industry_division | TEXT | 行业大类。干扰 | 否 |
| industry_code | TEXT | 行业代码。干扰 | 否 |
| business_scope | TEXT | 经营范围。干扰，不能代替行业或科技资质 | 否 |
| employee_count | INTEGER | 员工人数。干扰，不能代替 insured_count | 否 |
| external_score | INTEGER | 外部评分。干扰 | 否 |
| group_name | TEXT | 所属集团。干扰，不把集团数据算到成员企业 | 否 |
| data_authorization | TEXT | 数据授权。只有「已授权」才允许预审 | 是 |
| authorization_no | TEXT | 授权书编号。干扰 | 否 |
| authorization_date | TEXT | 授权日期。干扰 | 否 |
| authorization_scope | TEXT | 授权范围。干扰 | 否 |
| is_high_tech | INTEGER | 高新技术企业。1 表示是。科技资质三列满足其一即可 | 是 |
| is_specialized | INTEGER | 专精特新。1 表示是。科技资质三列满足其一即可 | 是 |
| invention_patent_count | INTEGER | 有效发明专利。不少于 1 即满足科技资质的这一项 | 是 |

## tax

税务。一家企业一行。

| 列 | 类型 | 含义 | 是否参与预审 |
| --- | --- | --- | --- |
| enterprise_id | TEXT | 对应 enterprise.enterprise_id | 否 |
| tax_credit_rating | TEXT | 纳税等级。A、B、M、C。不看 tax_credit_description | 是 |
| taxpayer_type | TEXT | 纳税人资格。产品有要求时才比较 | 是 |
| rating_year | TEXT | 评价年度 | 否 |
| tax_arrears | INTEGER | 欠缴。1 表示欠缴，整笔产品不准入 | 是 |
| tax_arrears_balance_wan | REAL | 欠税余额，万元。干扰，不能代替 tax_arrears | 否 |
| tax_paid_12m_wan | INTEGER | 近 12 个月纳税额，万元。税贷收入口径只看这一列 | 是 |
| tax_paid_24m_wan | INTEGER | 近 24 个月纳税额，万元。干扰 | 否 |
| prior_year_taxable_income_wan | INTEGER | 上年度纳税收入，万元。干扰 | 否 |
| revenue_wan | INTEGER | 营业收入，万元。干扰 | 否 |
| vat_filing_status | TEXT | 增值税申报状态 | 否 |
| tax_credit_description | TEXT | 纳税信用描述。干扰，不能代替 tax_credit_rating | 否 |

## social_security

社保。一家企业一行。

| 列 | 类型 | 含义 | 是否参与预审 |
| --- | --- | --- | --- |
| enterprise_id | TEXT | 对应 enterprise.enterprise_id | 否 |
| insured_count | INTEGER | 参保人数。人数只看这一列 | 是 |
| social_security_arrears | INTEGER | 欠缴。1 表示欠缴。为空则社保未获取 | 是 |
| contribution_base_wan | INTEGER | 缴纳基数，万元。干扰 | 否 |
| pension_insured_count | INTEGER | 养老参保人数。干扰，不能代替 insured_count | 否 |
| latest_payment_month | TEXT | 最近缴费年月 | 否 |
| payment_status | TEXT | 缴费状态。干扰，欠缴只看 social_security_arrears | 否 |

## judicial

司法。一家企业一行。失信限制只看严重失信和被执行。

| 列 | 类型 | 含义 | 是否参与预审 |
| --- | --- | --- | --- |
| enterprise_id | TEXT | 对应 enterprise.enterprise_id | 否 |
| is_dishonest | INTEGER | 严重失信。1 表示是，则失信限制 | 是 |
| is_enforced | INTEGER | 被执行。1 表示是，则失信限制 | 是 |
| case_summary | TEXT | 案件摘要。干扰 | 否 |

## dishonest_record

失信明细。不单独作为准入开关。

| 列 | 类型 | 含义 | 是否参与预审 |
| --- | --- | --- | --- |
| record_id | INTEGER | 主键 | 否 |
| enterprise_id | TEXT | 对应 enterprise.enterprise_id | 否 |
| case_no | TEXT | 案号。明细，不单独作为准入开关 | 否 |
| published_date | TEXT | 发布日期 | 否 |
| performance_status | TEXT | 履行情况 | 否 |

## enforcement_record

被执行明细。不单独作为准入开关。

| 列 | 类型 | 含义 | 是否参与预审 |
| --- | --- | --- | --- |
| record_id | INTEGER | 主键 | 否 |
| enterprise_id | TEXT | 对应 enterprise.enterprise_id | 否 |
| case_no | TEXT | 案号。明细，不单独作为准入开关 | 否 |

| 列 | 类型 | 含义 | 是否参与预审 |
| --- | --- | --- | --- |
| record_id | INTEGER | 主键 | 否 |
| enterprise_id | TEXT | 对应 enterprise.enterprise_id | 否 |
| case_no | TEXT | 案号。已结案件，不构成失信限制 | 否 |
| cause | TEXT | 案由 | 否 |
| status | TEXT | 状态 | 否 |
| closed_date | TEXT | 结案日期 | 否 |

## financing_history

历史融资。一户可以有多笔。逾期只看逾期未结清。

| 列 | 类型 | 含义 | 是否参与预审 |
| --- | --- | --- | --- |
| facility_id | TEXT | 业务编号，主键 | 否 |
| enterprise_id | TEXT | 对应 enterprise.enterprise_id | 否 |
| product_name | TEXT | 历史产品名称 | 否 |
| status | TEXT | 已结清或未结清 | 否 |
| overdue_unsettled | INTEGER | 逾期未结清。1 表示是，则不准入。已结清且本列为 0 的不触发 | 是 |
| ever_overdue | INTEGER | 曾逾期。干扰 | 否 |
| lender | TEXT | 贷款机构 | 否 |
| disbursed_amount_wan | INTEGER | 发放金额，万元 | 否 |
| loan_balance_wan | INTEGER | 贷款余额，万元。干扰，不能代替 overdue_unsettled | 否 |
| guarantee_type | TEXT | 该笔历史融资的担保方式 | 否 |
| disbursed_date | TEXT | 发放日期 | 否 |
| maturity_date | TEXT | 到期日期 | 否 |
| overdue_amount_wan | INTEGER | 逾期金额，万元。干扰，不能代替 overdue_unsettled | 否 |
| remark | TEXT | 备注。干扰 | 否 |
